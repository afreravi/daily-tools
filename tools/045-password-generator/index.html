    Why a random password generator beats a clever one

    Most weak passwords are not weak because their owner was careless. They are weak because humans are predictable. We reach for names, dates, keyboard runs and the same three substitutions — a for @, o for 0, e for 3 — that every cracking tool already knows by heart. A generator sidesteps the habit entirely. It picks each character from a pool using a cryptographically secure random source, so the result carries no memory, no pattern and no connection to you.

    This password generator runs entirely in your browser. Nothing you type or generate is sent anywhere, stored or logged. You can disconnect from the internet after the page loads and it will still work, which is exactly the property you want from a tool that handles secrets.

    How the tool works

    Two numbers decide how strong a password really is: the size of the character pool and the length of the string. The pool is everything you allow. Lowercase gives 26 characters, uppercase another 26, digits 10, and a typical symbol set around 32. Turn everything on and the pool is roughly 94 characters.

    Strength is measured in entropy, expressed in bits, calculated as length multiplied by the base-2 logarithm of the pool size. Each extra bit doubles the number of guesses an attacker needs. That is why length matters so much more than complexity: adding one character to a 94-symbol pool adds about 6.5 bits, while switching from lowercase-only to every character set on a short password adds far less.

    The read-out above converts those bits into a crack time, assuming an offline attack trying 100 billion guesses per second — a realistic figure for a dedicated attacker with modern graphics cards against a fast, unsalted hash. Your actual risk depends on how the site stored your password, but the comparison between your options holds either way.

    When to use a password generator

    • New account sign-ups. Generate the password at the moment you create the account, save it to your password manager, and never type it by hand again.
    • Replacing a reused password. If the same password protects your email, bank and a shopping site, one breach exposes all three. Generate a fresh, unique string for each.
    • Router, Wi-Fi and device admin panels. Default credentials are public knowledge. Long generated passwords belong on anything with a login page.
    • API keys and test data. Use the batch option to produce several distinct values at once when you need throwaway secrets for a staging environment.
    • Sharing a temporary credential. Generate a long password, share it through a secure channel, and change it once the task is done.

    Pro tips for stronger results

    Go long before you go exotic. A 20-character password using only letters and digits is stronger than an 8-character one using every symbol on the keyboard, and it is easier to handle.

    Let the tool exclude look-alikes when you must type it. The switch that removes 0 O o 1 l I | costs you a fraction of a bit and saves a lot of frustration on a phone or a printed label. For a password you will only ever paste from a manager, leave them in.

    One password, one account. The single biggest real-world gain is not length at all — it is uniqueness. A strong password reused across ten sites is a single breach away from being ten compromised accounts.

    Store it in a manager. A password manager turns the impossible task of memorising forty random strings into the manageable task of remembering one good passphrase.

    Common mistakes to avoid

    Adding a capital letter and an exclamation mark to a dictionary word does not make it strong; cracking tools test those patterns first. Reusing one excellent password everywhere still leaves every account exposed when the weakest site leaks. Shortening a password to something typeable quietly throws away most of the entropy you just generated. And writing the password in a plain text file, a chat message or a sticky note undoes the whole exercise — keep it in a manager, or memorise a passphrase you build yourself.

    Frequently asked questions

    Is this password generator safe to use? Yes. Generation happens locally in your browser with the Web Crypto API, and no password ever leaves your device.

    How long should my password be? Use at least 16 characters for email, banking and anything holding personal data. Twelve is a reasonable floor for low-value accounts; 20 or more costs you nothing when a manager stores it.

    Are symbols really necessary? They enlarge the pool, which helps, but length contributes more. A long alphanumeric password is a perfectly sound choice.

    What is entropy, in plain terms? It is a count of how many possibilities an attacker has to sift through, measured in bits. Each bit doubles the work required.

    Should I use a passphrase instead? For the one password you actually memorise, yes — four or five random words are long and easy to recall. Use generated strings everywhere else.
