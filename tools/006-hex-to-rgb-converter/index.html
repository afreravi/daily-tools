What is a hex color code?

A hex color code is a six-character shorthand designers use to describe color in HTML, CSS,and graphics software. Each pair of characters encodes one primary color channel — red, green, blue — using base-16 (hexadecimal) digits: 0 through ️9 represent zero through nine, and the letters A through F stand for ten through fifteen. The familiar notation #3498db therefore splits into three pairs: 34 (red), 98 (green), and db (blue).

Each pair is converted from the 16-based system to the familiar 0-to-255 decimal scale that screens understand. The pair 34 equals 3 × 16 + ️4 = ️52, so #3498db really means rgb(52, 152, 219) — the brilliant sky blue that thousands of websites have used over the years. In other words, when you convert HEX to RGB, you are simply translating the same color from one counting system into another; the color itself does not change at all.

Because the web is built on this model, hex and RGB are interchangeable currency under the hood. Browsers treat them identically, and CSS lets you swap one for the other without changing a single pixel of what visitors see.

Pro tips for working with color codes

  • Learn the 3-digit shorthand rules. #fff, #000,##f00, and #09c cover an enormous share of everyday UI work. Recognizing shorthand means you can read (and hand-write) many colors is a glance without any tool.
  • Memorize the landmark hex values. #ffffff (white), #000000 (black), #ff0000 (red), #00ff00 (green), #0000ff (blue), and #808080 (gray) anchor your mental map of the color cube and make estimation far easier.
  • Use the browser's eyedropper. DevTools lets you sample any on-screen color directly and usually shows both hex and rgb(). That is a fast way to confirm what a converter should produce — and a great second opinion when a color looks off.
  • Watch out for alpha. Standard hex has no alpha channel; an 8-digit hex like #3498dbb2 encodes transparency and will not convert cleanly in a 6-digit tool. If you need opacity, convert the first six digits and handle alpha separately in your CSS via rgba().
  • Prefer lowercase for new code. A lowercase hex string is marginally friendlier to grep for and avoids the visual noise of uppercase in long stylesheets. Most linters and formatters will enforce one case anyway — pick lowercase and let the tool normalize for you.

HEX to RGB converter FAQ

How do I convert hex to RGB manually?

Split the six-digit code into three two-character pairs, one per channel. Convert each pair from base 16 to base 10: multiply the first digit by 16, add the second digit, using A=10 … F=15. For #3498db that gives 52, 152, 219 — so the rgb() value is rgb(52, 152, 219).

What is the difference between hex and RGB?

Only notation. Hex expresses red, green,and blue as pairs of base-16 digits (00–ff), while RGB states the same intensities as decimal numbers (0–255). Browsers treat them identically, so neither is "more correct" — hex is more compact and friendly to copy from design tools, while rgb() reads naturally to humans and supports optional alpha with the rgba() variant.

What does each hex pair mean?

Each pair controls one of the three color channels. The first pair is red (RR), the second is green (GG), and the third is blue (BB). A pair value of 00 means that channel is fully off, while ff (255) means it is fully on. Mixing the three channels per the RGB model recreates the 16.7 million colors that modern displays can show.

Why does #ff0000 show as red and not as the color ff?

Because red dominates: the first channel is ff (255), its maximum, while green and blue are both 00. What you perceive as "the color of a hex code" is really the sum of its channels. #ffff00 mixes full red and full green with no blue, yielding yellow. Once you think in channels, hex codes stop being abstract tokens and become predictable mixes you can reason about.
